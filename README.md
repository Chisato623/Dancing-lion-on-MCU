# 基于 MSPM0G3507 的醒狮控制程序

这是一个基于 TI MSPM0G3507 单片机的醒狮控制程序，整合了语音识别、舵机动作、LCD 表情显示和音乐触发控制。

根目录下的 `motor` 和 `voice` 文件夹中保留了初版代码；根目录中的源码则将语音、舵机、LCD、音乐触发等模块合并并整理到了当前最终版本。

## 使用方法

1. 在 MSPM0 SDK 的 `driverlib` 示例目录中新建项目文件夹，例如：

   ```text
   E:\mspm0_sdk_1_30_00_03\examples\nortos\LP_MSPM0G3507\driverlib
   ```

2. 将本项目解压或克隆到该目录下。
3. 使用 Keil 工程打开并编译下载。

如果项目没有放在上述 SDK 示例路径附近，可能会因为缺少头文件或相对路径不匹配导致编译报错。

## 当前已实现功能

- 语音识别控制
- 舵机操控醒狮动作，包括前进、坐下、站立、跳舞、停止
- LCD 屏幕显示，包括欢迎画面和多种表情绘制
- 跳舞动作时触发 MP3/音乐播放控制引脚
- UART 调试与命令输入

## 引脚分配表

| 引脚 | 功能 | 外设实例 | 说明 |
|------|------|----------|------|
| **PA0** | UART TX | `UART_0` (UART0) | 串口发送 |
| **PA1** | UART RX | `UART_0` (UART0) | 串口接收 |
| **PA12** | GPIO 输出 | `GPIO` | LED 指示灯 |
| **PA13** | GPIO 输出 | `MP3` | 跳舞时拉高，用于触发音乐播放 |
| **PA15** | PWM CCP2 | `PWM_MOTOR2` (TIMA0) | 右后舵机 |
| **PA17** | PWM CCP3 | `PWM_MOTOR2` (TIMA0) | 右前舵机 |
| **PA19** | SWDIO | DEBUGSS | 调试数据 |
| **PA20** | SWCLK | DEBUGSS | 调试时钟 |
| **PA21** | PWM CCP0 | `PWM_MOTOR2` (TIMA0) | 左后舵机 |
| **PA22** | PWM CCP1 | `PWM_MOTOR2` (TIMA0) | 左前舵机 |
| **PA24** | GPIO 输出 | `LCD` | LCD DC 数据/命令选择 |
| **PA25** | GPIO 输出 | `LCD` | LCD RES 复位 |
| **PA26** | GPIO 输出 | `LCD` | LCD SDA 软件模拟 SPI 数据 |
| **PA27** | GPIO 输出 | `LCD` | LCD SCL 软件模拟 SPI 时钟 |
| **PA28** | I2C SDA | `I2C_0` (I2C0) | 语音模块数据线 |
| **PA31** | I2C SCL | `I2C_0` (I2C0) | 语音模块时钟线 |
| **PB7** | GPIO 输出 | `IN4` | 方向控制 IN4 |
| **PB19** | GPIO 输出 | `IN2` | 方向控制 IN2 |
| **PB20** | PWM CCP0 | `PWM_MOTOR1` (TIMG12) | 电机 1 CH0 |

## 语音命令

| 命令 | 功能 |
|------|------|
| 唤醒 | 初始化/回到中位 |
| 前进 | 执行连续前进步态 |
| 坐下 | 前腿保持水平，后腿向后坐下 |
| 站立 | 所有舵机回到中位 |
| 跳舞 | 后腿保持坐下，前腿交替摆动，同时拉高 MP3 引脚 |
| 停止 | 停止当前动作并回到中位 |

## 说明

- 舵机为 SG90 90 度舵机，代码中对角度做了限制，避免超出机械安全范围。
- MP3 控制引脚为 PA13，仅在跳舞动作执行期间拉高，其余动作和初始化状态均拉低。
- LCD 表情显示已去除不必要的状态文字，只保留表情图形。
